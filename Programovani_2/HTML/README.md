# HTML

Tato složka obsahuje moje úlohy a cvičení z **HTML** v předmětu Programování 2.

## Co se zde učíme

- základní strukturu HTML dokumentu
- nadpisy a odstavce
- formátování textu
- speciální HTML znaky a entity
- seznamy `ul`, `ol` a `dl`
- tabulky
- práci s atributy jako `colspan`

## Soubory

- `index.html` – průběžný soubor s úlohami a příklady z hodin

Obsah budu postupně doplňovat podle probírané látky.
