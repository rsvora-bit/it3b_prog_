# CSS

Tato složka je určená pro moje úlohy a cvičení z **CSS** v předmětu Programování 2.

CSS budeme používat pro vzhled a úpravu HTML stránek.

## Co zde bude

- barvy a pozadí
- písmo a text
- okraje a rámečky
- velikosti a mezery
- rozložení prvků na stránce
- další CSS vlastnosti podle výuky

Obsah budu postupně doplňovat podle probírané látky.
