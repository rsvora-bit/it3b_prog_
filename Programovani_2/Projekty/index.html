Příběh internetu a webu

Internet není totéž co web

Internet je celosvětová síť propojených počítačových sítí. World Wide Web je služba, která přes internet propojuje dokumenty a stránky pomocí odkazů. Když si otevřeš web, používáš internet – ale internet umožňuje také e-mail, hovory a mnoho dalších služeb.

Vědec Tim Berners-Lee předložil návrh webu v CERNu v roce 1989. Do konce roku 1990 už na počítači NeXT fungoval první server i prohlížeč. Web se postupně stal dostupným celému světu.

Zajímavost: První server měl varovný nápis, aby jej nikdo omylem nevypnul.
